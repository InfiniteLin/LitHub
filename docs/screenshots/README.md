# 截图说明

根目录 `README.md` 引用了这个目录下的 6 张图，**文件名必须完全一致**，否则图片显示不出来。

截的时候建议：

- 应用窗口拉到 **1440×880** 左右；高分屏可以直接按 2× 截，这样在 Retina 上也清晰
- 用 `Win + Shift + S` 或任意截图工具，**只截应用窗口本身**（不要带桌面背景和其它窗口）
- 存成 PNG，覆盖到本目录同名文件

| 文件名 | 截什么 | README 里用在哪 |
|---|---|---|
| `reader-dual.png` | 阅读器 · 双语对照模式（左原文右译文） | 顶部主图 |
| `library.png` | 文献库列表（几篇文献，最好带分类树和标签） | 「文献库」 |
| `library-tree.png` | 文献库，展开某篇的附件树（原文/译文/对照/笔记那几个子项） | 「文献库」第二张 |
| `notes.png` | 笔记面板打开的状态（有 Markdown 正文，带公式或表格更好） | 「笔记」 |
| `webai.png` | 网页 AI 嵌在右侧、和论文并排 | 「网页 AI 内嵌」 |
| `library-dark.png` | 深色模式下的文献库 | 「外观」 |

哪张暂时截不了（比如网页 AI 登录态没准备），把那一段 `<p align="center">...</p>` 整块从 README 里删掉即可 —— 别留着空链接，GitHub 上会显示成破图。
